# Kashmiri Ventures WordPress Website

A custom WordPress website for Kashmiri Ventures, a tour company offering tour packages across Pakistan (Hunza, Skardu, Fairy Meadows, Naran Kaghan, Swat, Kashmir and more). The site is live and hosted on InfinityFree.

## Live Website

[View Kashmiri Ventures Website](https://kashmiriventures.page.gd/)

## Project Overview

A responsive tour and booking website with a custom theme and a custom plugin. Tours, destinations, prices, pictures and homepage sections can be managed from the WordPress admin area (wp-admin).

## Main Features

- Tour packages and destination pages
- Booking form and booking confirmation page
- Customer reviews, gallery and FAQs pages
- About and Contact pages
- Homepage sections editable from wp-admin

## Technologies

- WordPress (custom theme and custom plugin)
- PHP
- HTML5
- CSS3
- JavaScript
- MySQL / WordPress database

## Repository Structure

- `wp-content/themes/kashmiri-ventures` - custom WordPress theme
- `wp-content/plugins/kv-core` - custom plugin (tours, bookings, admin settings)

## Repository Scope

This repository contains only the custom theme and plugin. WordPress core files, the database, `wp-config.php`, uploads and server login details are intentionally not included.
